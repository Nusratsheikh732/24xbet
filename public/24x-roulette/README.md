# 1X Velvet Speed Roulette

A self-contained, mobile-first Live Roulette web game matching the 1X Velvet Speed Roulette video interface.

## How to Run on Bolt.new / StackBlitz / Local
1. Upload or drag-and-drop this ZIP archive directly into **Bolt.new** or **StackBlitz**.
2. Or run locally:
   ```bash
   npm install
   npm run dev
   ```
3. Open `index.html` directly in any web browser if you prefer running without any build tools.

## Features Included
- High-definition live video frames of dealer and studio from video
- 3D ball physics with multi-stage orbit, deflection bounce, and pocket settlement
- Multi-camera angles (Betting View, Close-Up Launch, Top-Down Overhead, Front View)
- Responsive portrait betting board with animated chip placement
- 7-chip selector fan (50 to 100k)
- Racetrack call bets, statistics, favorite bets, and deposit modal
